Privacy

What Port0r keeps.

Port0r is a free fan project made by one person. Here is everything the games and this site send, and what is kept. No ads, nothing sold, nothing shared.

The games on Quest

  • "All files access" is used to read the game files you copied to the headset, and to keep your settings in the Port0r folder.
  • "Install unknown apps" is used only to install a Port0r update you accept.
  • To tell you when an update is out, the game asks GitHub for the list of Port0r releases. GitHub sees that request like any other.
  • The first time it runs, the game makes up a random number for the headset. It isn't tied to your Meta account, your name or the headset's serial number. The game sends it to Port0r's server (alloxr.info) to check whether this headset is linked to the Port0r Discord and, in the games with a weekly prize, whether it won it.
  • Linking to Discord is optional. If you type the code from the headset to the Port0r bot, or sign in with Discord on the link page, the server keeps your Discord user ID and display name next to the headset's number, so your times and scores show under your name in #leaderboard. Each score you publish is kept with the game, the stage, the time or score and the game's version.

This site

  • GitHub Pages hosts port0r.com, so GitHub receives your requests like any web host. The fonts come from Google Fonts, so Google sees that request too. A video loads YouTube's player (youtube-nocookie.com) only when you press play.
  • To count visits, each page tells Port0r's server it was seen: the page, the site you came from (and a link's campaign tag, if it has one), the kind of device (Quest, phone, computer), the browser's and system's names, the language, the time zone, the window's width, how long the page was on screen, and which outside link or video you opened.
  • No tracking cookie. Your chosen appearance and whether to play the intro are saved only in this browser. To count visitors without following them, the server mixes your IP address and browser with a key that changes every day and keeps only the result. The IP itself isn't written, and each day's key is deleted the next day.
  • The contact form: what you write (name, e-mail, topic, message) is stored on Port0r's server and sent by e-mail to Port0r so the person who makes the games can answer you. Your IP address is kept only as a scrambled code, to stop spam.
  • The live numbers and the leaderboards are read from Port0r's server and from GitHub.

Port0r's server

  • Like any web server, alloxr.info keeps a log of requests (IP address, time, address asked for, browser) for 14 days, for security and to fix problems.

Discord

  • The Port0r Discord runs on Discord, and Discord's own privacy policy applies there.
  • In #ask-port0r the bot answers with Google's Gemini: what you write to it is sent to Google to get the answer.

Your data

  • To unlink your headset, delete your scores or your messages, or ask what is kept about you, write through the contact page. It gets deleted.
